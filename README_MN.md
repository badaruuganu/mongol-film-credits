# Киноны уран бүтээлчдийн веб MVP (Монгол кирилл)

## Чухал тайлбар
Энэ багц нь браузерын интерфейс + серверийн эх код. Энэ нь одоогоор олон нийтэд байршуулсан шууд веб хаяг биш. Интернэтэд ажиллуулахын тулд Docker дэмждэг серверт байршуулна. Киноны сувгийн мэдээлэлд огт төвлөрөхгүй; зөвхөн видео нэр, линк, титрийн OCR үр дүнг ашиглана.

## Функц
- YouTube линк оруулах UI
- Сервер дээр видеог боловсруулахыг оролдох
- Видеоны сүүлийн 20 минутаас 1.5 секунд тутамд кадр гаргах
- Tesseract OCR-оор `mon+eng` текст таних
- Титрийн текстийг энгийн дүрмээр ангилах
- Үр дүнг Монгол кирилл `.xls` файл болгох
- OCR мөр, ангилал, кадрын цаг, эх линкийг харуулах

## Хязгаарлалт
Энэ нь туршилтын MVP. Төгсгөлийн титрийг OCR-оор уншина; хүний нэрийг найдвартай entity болгон салгаж, жүжигчин ↔ дүрийг үргэлж зөв холбохгүй. Бүрэн автомат, өндөр чанартай хувилбарт LLM extraction, киноны мэдээллийн сангийн тулгалт, duplicate matching, гар аргаар баталгаажуулах интерфейс хэрэгтэй. OCR нь зарим видеонд олон мянган давхардсан мөр үүсгэж болно.
YouTube-ийн видео таталт нь видео нийтийн эсэх, нас/бүсийн хязгаарлалт, YouTube-ийн нөхцөл болон эрхээс хамаарна. Зөвхөн ашиглах эрхтэй контентод хэрэглэнэ.

## Docker ашиглан ажиллуулах (сервер эсвэл локал туршилт)
Docker Desktop суулгасан Windows дээр PowerShell-оор төслийн хавтас руу орно:

```powershell
docker build -t mongol-film-credits .
docker run --rm -p 8080:8080 -v "${PWD}/data:/app/data" mongol-film-credits
```

Дараа нь браузер дээр http://localhost:8080 нээнэ.

Docker image-д FFmpeg, Tesseract, англи ба Монгол хэлний өгөгдөл суулгахыг оролддог. Хостын Linux репозиторид `tesseract-ocr-mon` багц байхгүй бол Dockerfile-ийг тухайн орчны дагуу өөрчлөх хэрэгтэй.

## Нийтийн веб болгох
- Docker дэмждэг сервер/үйлчилгээ сонгох
- HTTPS тохируулах
- Урт хугацааны видео боловсруулалтыг background queue (Redis/Celery гэх мэт)-д шилжүүлэх
- Нэг хэрэглэгчийн файлд хандах эрхийг тусгаарлах, rate limit, хадгалалтын хугацаа тохируулах
- YouTube-ийн нөхцөл, зохиогчийн эрх болон хостын дүрмийг шалгах
- Видео файлуудыг хадгалахгүйгээр боловсруулах, дуусмагц устгах бодлого хэрэгжүүлэх

## Хөгжүүлэлтийн горим
Windows дээр Python 3.11+, FFmpeg, Tesseract (мон+eng хэлний өгөгдөл) суулгасны дараа:

```powershell
py -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python app.py
```
Орон нутгийн хөгжүүлэлтийн хаяг: http://127.0.0.1:5000
